# わたしのスキルマップ（スプレッドシート連携版）

- 看護師さん用：公開URLのトップ（QRコードから開いて回答 → 自動でスプレッドシートへ送信）
- 管理者用：公開URLの末尾に `admin/`（スプレッドシートの回答を読み込んで分析）

## 初回設定（管理者・1回だけ）
### A. Googleスプレッドシートを準備する
1. Google ドライブで新しいスプレッドシートを作る（例：わたしのスキルマップ_回答）
2. メニュー「拡張機能」→「Apps Script」
3. 最初から入っているコードをすべて消し、`apps-script.gs` の中身を貼り付ける
4. 7行目の `ADMIN_KEY` の 'ここを管理者用パスワードに変更' の部分を、管理者だけが知るパスワードに書き換えて保存（💾）
5. 右上「デプロイ」→「新しいデプロイ」→ 歯車 →「ウェブアプリ」
   - 次のユーザーとして実行：自分
   - アクセスできるユーザー：全員
6. 「デプロイ」→ アクセスを承認（「このアプリは Google で確認されていません」と出たら「詳細」→「（安全ではないページ）に移動」→「許可」）
7. 表示された「ウェブアプリのURL」（…/exec）をコピー

### B. アプリに受付URLを設定する
1. `config.js` をメモ帳で開き、`gasUrl: ''` の '' の中に A-7 のURLを貼り付けて保存
2. GitHub のリポジトリに、このフォルダの中身をすべて上書きアップロード

### C. 管理者用画面で読み込む
管理者用URL →「設定・データ」→「スプレッドシート連携」に管理者パスワードを入れて「保存して読み込む」

## 回答期間の設定
管理者用ページ「設定・データ」→「回答期間」で開始日・終了日を保存します（スプレッドシートの「回答期間」シートに書き込まれます）。期間外は看護師さんの画面で回答を始められず、送信も受け付けません。

## 注意
- 回答（氏名と評価）は管理者の Google アカウントのスプレッドシートに保存されます。院内の個人情報の取り扱いルールを確認のうえ利用してください。
- Apps Script のコードを変えたときは「デプロイ」→「デプロイを管理」→ 鉛筆 → バージョン「新バージョン」→「デプロイ」で反映します（URLは変わりません）。
- ファイルを更新したときは `sw.js` の `VERSION` を変えると端末側に反映されやすくなります。
